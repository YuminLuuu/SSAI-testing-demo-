# 极端天气下的独居适应工具 — 原型

一个面向独居、生活经验有限人群的极端天气行动清单原型。核心主张：**不是知识库，是一份会根据居住情况变化的行动清单**。

## 文件

| 文件 | 是什么 |
|---|---|
| `index.html` | 可交互原型（v0.1）。台风全时间轴 + 三个个性化问题 + 求助话术模块。纯静态，无依赖，可离线打开。 |
| `prototype-v2.html` | **出行助手 v2.0 可交互原型**。按 PRD v2.0 实现：5 输入端 → 风险评估引擎 → 6 模块行动方案，四个 tab + 常驻 SOS。视觉风格 Playful Editorial。纯静态，无后端。 |
| `docs/prompt-spec.html` | 提需求规范卡。从 SheShapesAI 工作坊实录（Job Hunt Copilot 八步实录）提炼的 prompt 模板与规范，含套用到本项目的现成 Define prompt。 |
| `docs/positioning.html` | 对内定位说明。气候适应 / 防灾减灾的概念坐标、我们在动哪个变量、语言纪律、衡量指标、停止条件。**不对外、不对用户使用。** |

## 出行助手 v2.0 原型（`prototype-v2.html`）

对应 PRD v2.0 的可交互原型，验证的是「打开即答案」这条核心链路能不能在一屏内成立。

**能玩的地方**

- 点顶部天气条 → 6 个预设模板 + 7 个参数滑杆，整套方案实时重算（输入端①静态天气数据库）
- 「今日状态」三组一键确认，选「不出门」整页切换为居家安全方案（输入端③）
- 「我的」里改行动方式 / 居住状态 / 健康基线，回到「今日」看风险机制被过滤或加权（输入端②）
- 每条行动项可展开「为什么是这条」，带来源标注（天气 / 画像 / 健康历史 / 无障碍上报）
- 宽屏左侧固定「风险评估引擎」读数面板：5 路输入 → 7 个机制的独立评分，灰掉的是没触发或与你无关被过滤的
- 分享、SOS、紧急信息卡、健康记录与无障碍上报表单均可点开

**设计风格**：Playful Editorial。刊头 + 大日期数字 + 栏目号的杂志结构，配盲道黄（取自无障碍导向砖）与硬边投影。无障碍前置：正文 ≥15px、点击区 ≥44px、语义色永远配文字标签、支持深浅两套主题与 `prefers-reduced-motion`。

**技术**：单文件、无依赖、无后端、无网络请求（Google Fonts 除外）。风险评分函数集中在 `engine()`，新增一个机制只需加一个评分块。

## 原型验证的是什么

不是"信息够不够全"，而是三件事：

1. 按**时间阶段**（T-72h / T-24h / 进行中 / 灾后）而非知识分类来组织，用户是否更容易照做
2. 三个个性化问题（楼层、租/自有、同城有无可求助的人）产生的差异，用户是否感知得到
3. **「该找谁 + 怎么开口」**这一块，是不是比应对知识本身更有价值

## 结构

- **动作卡**固定字段：动作 / 为什么 / 怎么做 / 耗时与花费 / **这事该不该我自己做** / 最常见的错 / 做完怎么算对
- **求助话术**：每个场景对应「找谁 → 何时打 → 可直接复制的一段话」
- 进度存在 `localStorage`，无账号、无后端、无网络请求（字体除外）

## ⚠️ 内容状态

原型中的具体数字与处置方法**全部是待核对的草稿**。在给任何真实用户使用之前，必须逐条比对应急管理部门、当地气象台、红十字会的公开指引并标注来源。涉水深度、中暑判断、食物安全这几类写错会出事。产品任何时候都不得与官方预警相矛盾。
