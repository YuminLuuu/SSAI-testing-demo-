# 极端天气下的适应工具 — 原型

面向独居者、行动不便者、生活经验有限人群的行动清单原型。核心主张：**不是知识库，是一份会根据你今天的处境变化的行动清单**。

v0.3 换了一条路子：不再靠预先写好的内容库，而是把**个人档案、实时天气、健康记录**三块数据放在一个入口，最后交给大模型生成当日清单。面向的人群也更具体了——肢体障碍者（尤其是使用间歇导尿、电动轮椅的脊髓损伤者）、有基础疾病者、独居者。

v0.2 及更早的版本保留作对照：v0.2 是预写内容 + 规则筛选的三路径工具，v0.1 是台风单情境的时间轴清单。

## 文件

| 文件 | 是什么 |
|---|---|

| `app.html` | 可交互原型（v0.2）。 按需求文档的三条路径 + 常驻紧急求助搭的完整信息架构：天气应对 / 日常无障碍资源 / 健康笔记本 / 紧急求助。纯静态，无依赖，可离线打开。 |
| `index.html` | 可交互原型（v0.1）。台风单情境的全时间轴 + 三个个性化问题 + 求助话术模块。保留作为对照。 |
| `docs/prd.html` | **产品需求文档（PRD v0.2）。** 问题与目标用户、三条路径的逐条功能需求与验收标准（A/B/C/D/E 共 27 条）、内容红线、数据与隐私、指标、里程碑、六个待决策问题与四条停止条件。 |
| `docs/prompt-spec.html` | 提需求规范卡。从 SheShapesAI 工作坊实录（Job Hunt Copilot 八步实录）提炼的 prompt 模板与规范，含套用到本项目的现成 Define prompt。 |

## v0.2 的结构（对应需求文档的路径树）

| 路径 | 流程 | 原型里做到哪一步 |
|---|---|---|
| **A · 天气应对** | 选情境（高温 / 暴雨 / 台风 / 寒潮）→ 补充个人情况（是否外出、身体状态、是否独居、行动能力、出行需求）→ 今日行动建议 | 完整可走。建议页按「当前风险 → 与我有关的影响 → 现在先做什么」三段展开，下接 3–5 条优先行动；支持朗读、放大字号、收藏、标记完成、继续提问 |
| **B · 日常无障碍资源** | 浏览（路不好走 / 通道被占 / 电梯停运 / 其他）→ 按地点·类型·更新时间·是否仍有效筛选 → 用户补一条 → 标记是否失效 | 完整可走，含 6 条种子数据。「今天还是这样 / 已经恢复了」直接改状态与计数，可收藏常用地点 |
| **C · 健康笔记本** | 查看记录（身体反应 / 出行天气 / 用药 / 就医）→ 新增一条 → 系统整理成周期提醒与阶段总结 | 完整可走。阶段总结由记录实时算出（两周条数、天气相关比例、需后续关注的条数） |
| **常驻 · 紧急求助** | 一键进入 → 110 / 119 / 120 / 紧急联系人 → 现在先做什么·不要做什么·联系谁 → 紧急信息卡 | 完整可走。行动提示随当前天气情境变化；信息卡自动带入路径 A 的个人情况与路径 C 的用药就医记录，可编辑、可复制成文字 |

个人情况、记录、收藏、完成状态都存在 `localStorage`，无账号、无后端、无网络请求（字体除外）。

## 这一版待确认的问题

1. 用户从哪里进入？三条路径并列，还是天气应对为主、另两条藏在二级？
2. 路径 B 的信息来源：完全由用户互填，还是接入官方 / 第三方无障碍数据？冷启动阶段没人填时它还成不成立。
3. 路径 A 是否要接真实预警数据（气象台 API / 定位），还是保持"用户自己选情境"。
4. 路径 C 的数据敏感度：只留本地，还是要支持导出 / 同步给家人。
5. 紧急信息卡是否需要脱离 App 存在（锁屏可见、可打印、二维码）。

## v0.1 验证的是什么（仍然成立）

不是"信息够不够全"，而是三件事：

1. 按**时间阶段**（T-72h / T-24h / 进行中 / 灾后）而非知识分类来组织，用户是否更容易照做
2. 三个个性化问题（楼层、租/自有、同城有无可求助的人）产生的差异，用户是否感知得到
3. **「该找谁 + 怎么开口」**这一块，是不是比应对知识本身更有价值

## 动作卡结构（两版通用）

- **动作卡**固定字段：动作 / 为什么 / 怎么做 / 耗时与花费 / **这事该不该我自己做** / 最常见的错 / 做完怎么算对
- **求助话术**：每个场景对应「找谁 → 何时打 → 可直接复制的一段话」
- 进度存在 `localStorage`，无账号、无后端、无网络请求（字体除外）

## ⚠️ 内容状态

原型中的具体数字与处置方法**全部是待核对的草稿**。在给任何真实用户使用之前，必须逐条比对应急管理部门、当地气象台、红十字会的公开指引并标注来源。涉水深度、中暑判断、食物安全这几类写错会出事。产品任何时候都不得与官方预警相矛盾。

## 下一步

不是加内容，是拿这一版去问 8–12 个过去 12 个月真实经历过台风 / 暴雨 / 热浪的独居者与行动不便者：**哪一条你真的会做，哪一条你看了就划过去；三条路径里，你只会用哪一条。**
