# 我的专属行动清单 —— 原型 v0.3

把「我是谁」「今天天气怎么样」「我最近身体怎么样」放在同一个页面里，最后交给大模型生成一份只针对这个人的当日行动清单。

```
个人档案  ─┐
实时天气  ─┼─→  [生成我的专属行动清单]  ─→  claude-opus-5  ─→  结构化清单
健康记录  ─┘
```

## 跑起来

```bash
# 接真实模型
ANTHROPIC_API_KEY=sk-... node generator/server.js

# 只看界面和数据流，不花钱
node generator/server.js
```

然后打开 <http://localhost:5173>。Node 18+，零依赖。

不带 key 时服务端会返回一份内置的演示输出（`stub.json`），走的是和真实调用完全一样的流式链路与渲染路径——界面、字段、加载过程都一致，只是内容是固定的。

直接双击 `index.html` 也能打开，档案和健康记录都能填、能存，但实时天气和生成会提示需要服务端。

## 为什么要有 server.js

两个原因，都不是可选的：

1. **API key 不能进浏览器。** 页面里写 key，等于把 key 发给每一个打开页面的人。生成请求由本机服务端转发，key 只存在于 `server.js` 的进程环境变量里。
2. **天气服务留一个可替换的接缝。** 现在用 Open-Meteo（免费、无需 key）。要换成和风天气或其他需要 key 的服务，只改 `server.js` 里的 `getWeather()`，保持返回字段不变，前端一行都不用动。

服务端同时把模型返回的 SSE 消化成三种简单事件（`text` / `done` / `error`），浏览器不需要知道任何模型接口的细节。

## 三个窗口

| 窗口 | 收集什么 | 说明 |
|---|---|---|
| **01 我的情况** | 年龄、性别、肢体障碍类型与等级、损伤平面、辅助设备、自理程度、排尿方式、基础疾病、用药、过敏、居住情况 | 选「脊髓损伤」才会出现「损伤平面」；选「女」才会出现经期记录 |
| **02 今天的天气** | 定位或城市搜索取实时天气；四类典型情境（高温／暴雨／台风／寒潮）；是否出门、非做不可的事 | 有实时数据时会推荐一个情境，用户可以改。<b>拿不到天气也能用</b>——手动选情境即可 |
| **03 健康记录** | 导尿（量、颜色、不适）、饮水、经期、排便、体温血压、皮肤压疮检查 | 每条可改时间。今日汇总会算出饮水总量、导尿次数与总量、<b>最长导尿间隔</b>、单次最大尿量，并标出异常 |

## 生成

点击后把档案 + 天气 + **今日汇总数字**拼成提示词发给模型。具体每条记录的备注不发送。

返回的是受 JSON Schema 约束的结构化结果：

- `headline` —— 一句话说清今天对这个人意味着什么
- `risk_level` —— 低 / 中 / 高 / 很高
- `why_you` —— 这跟你有什么关系
- `actions[]` —— 每条含 `title` / `when` / `why` / `how[]` / `who` / **`based_on[]`**
- `watch_for[]` —— 看到什么征兆、立刻做什么
- `ask_doctor[]` —— 该问医生而不是问这个工具的问题

**`based_on` 是这一版最要紧的字段。** 每条行动都要标出它是根据用户哪几项信息给出的，并在界面上显示成蓝色小标签。个性化如果不能被看见，用户就会觉得这只是一份通用清单——这正是需要验证的假设。

请求参数：`claude-opus-5`，`thinking: {type:'adaptive'}`，`output_config.effort: 'high'`，流式返回。

## 安全边界

系统提示词里写死了几条：不做诊断、不建议用药或调整剂量、不与官方预警矛盾、信息不足时宁可少写也不编造、高危征兆必须写清楚"看到什么"和"立刻做什么"。

界面上有两处固定提示：顶部说明这不是医疗建议，结果底部重申未经核对、紧急情况拨 120。

**这些是原型级别的约束，不足以支撑真实用户使用。** 上线前必须做的：脊髓损伤相关内容经康复科医师复核；建立已核对语料并把模型输出约束在其中；对生成结果做审核抽样。

## 数据

全部存在浏览器 `localStorage` 的 `wx-v03` 键下，无账号、无后端存储。健康数据在中国属于敏感个人信息——这个原型的立场是本地优先，任何要打破它的功能都得先回答"不上传能不能做到"。

## 已知未验证

- 天气接口与模型接口的真实调用**未在开发环境验证过**（网络策略限制），代码路径已写好但需要在你的机器上首跑确认。
- 情境推荐的阈值（33℃ / 25mm / 39km/h / 5℃）是原型的粗略取值，正式版应对齐中国气象局的预警信号分级。
